# FinFlow — การเงินของฉัน

เว็บแอปจัดการและ **ทำนาย** การเงินส่วนตัว สร้างจากชีต `Simulation พื้นที่จำลอง` ของผู้ใช้
เป้าหมาย: เก็บความสามารถ "จำลองอนาคต" ของ Excel ไว้ แต่ทำให้ **ไม่พัง** และ **กดใช้บนมือถือได้จริง**

> ข้อมูลตั้งต้นเป็นรายการจริงจากไฟล์ Excel — 11 เดือน (ม.ค.–พ.ย. 2569) · รายรับ 34 · รายจ่าย 158 รายการ

## ปัญหาที่แก้ให้แล้ว

| ปัญหาใน Excel | แก้ยังไง |
|---|---|
| สูตรพัง `#REF!` ตั้งแต่เดือนกลางๆ อ่านอนาคตไม่ได้ | ยอดรวมคำนวณสดจาก array ไม่ใช่อ้างอิงเซลล์ — **ลบรายการทิ้งแล้วไม่มีทางขึ้น error** |
| รายจ่ายฟิก/ผันแปร/หนี้ ปนกันในแถวเดียว | แยก 4 หมวดตั้งแต่ต้น: ประจำ · ผันแปร · หนี้/บัตร · เงินออม |
| บัตรหลายใบยอดชนกัน ไม่รู้ใบไหนใกล้เต็ม | หน้าบัตรแยก มีวงแหวน % วงเงิน เรียงตามใกล้ครบกำหนดก่อน |
| ลืมเผื่อรายจ่ายจร → เดือนติดลบเฉียบพลัน | การ์ด "ควรรู้" เตือนล่วงหน้าว่าเดือนไหนจะติดลบเท่าไหร่ |
| ยอดหารครึ่งกับพี่บิวอยู่คนละชีต ตามไม่ทัน | หน้าหารครึ่ง สรุปยอดค้างสด แตะสลับคนจ่ายได้ |
| เงินเก็บกระจายหลายบัญชี ไม่เห็นภาพรวม | หน้าเงินเก็บ รวมทุกกระเป๋า + เส้นเป้าหมาย + กราฟสะสม |

## สิ่งที่ทำให้ใช้ง่ายจริง

- **แก้ได้ทุกช่อง** — แตะที่ชื่อหรือตัวเลขแล้วพิมพ์ทับได้ทันที ไม่ต้องเปิดหน้าต่างใหม่
- **ช่องตัวเลขรับสูตร** — พิมพ์ `3000+500` หรือ `1200*2` แล้วมันคิดให้ (เหมือนที่เคยชินใน Excel)
- **โน้ตได้ทุกรายการ** — ปุ่ม ✎ ท้ายแถว มีโน้ตแล้วจุดเปลี่ยนเป็นสีเหลือง
- **เดือนใหม่สร้างเองอัตโนมัติ** — กด › ไปเดือนที่ยังไม่มี ระบบจะยกรายจ่ายประจำ/หนี้/เงินออมจากเดือนล่าสุดมาให้ ไม่ต้องพิมพ์ใหม่
- **แยก "จริง" กับ "คาดการณ์"** — กดปุ่ม ● / ○ สลับได้ กราฟจะเปลี่ยนเป็นเส้นทึบ/เส้นประให้เอง
- **สำรอง/กู้คืนเป็นไฟล์ JSON** — ปุ่ม ⋯ มุมล่างซ้าย

## กติกาคำนวณ (มีข้อเดียว)

```
ยอดยกมา + รายรับ + เงินก้อนพิเศษ − รายจ่าย = เหลือสุทธิ
เหลือสุทธิเดือนนี้ = ยอดยกมาเดือนหน้า        ← ต่อกันเป็นลูกโซ่
```

แก้อะไรก็ตาม ลูกโซ่ทั้งเส้นคำนวณใหม่หมดทันที
**ทดสอบแล้ว:** เพิ่มค่าห้อง ก.พ. 2,000 บาท → ทุกเดือนถัดไปขยับ −2,000 ทั้งเส้น · ลบรายการทิ้ง → ไม่มี `NaN` สักช่อง

> **หมายเหตุ:** ตัวเลขบางเดือนจะไม่ตรงกับชีตเดิม เพราะสูตรในชีต**ไม่ตรงกันเองอยู่แล้ว**
> (เช่น พ.ค. ยอดยกมาคำนวณไม่ลงตัว ต่างไป ~5,848) แอปนี้ยึดรายการจริงแล้วคำนวณใหม่ให้ถูก

## โครงสร้างโค้ด

```
index.html            โครงหน้า + แถบนำทาง
css/app.css           ระบบดีไซน์ทั้งหมด (ตัวแปรสีอยู่บน :root)
data/seed.json        ข้อมูลจริงที่แปลงมาจาก Excel

js/util.js            จัดรูปตัวเลข/เดือนไทย + เครื่องคิดเลขในช่องกรอก
js/store.js           เก็บ/โหลด/บันทึก (localStorage) + สร้างเดือนใหม่
js/engine.js          กติกาคำนวณลูกโซ่ + การเตือน  ← หัวใจ
js/chart.js           กราฟ SVG เขียนเอง (เส้นทึบ/ประ, วงแหวน, แถบสัดส่วน)
js/edit.js            แก้ inline ทุกช่อง + โน้ต + แผงลอย
js/screens.js         6 หน้าจอ
js/app.js             สลับหน้า + เมนูข้อมูล
```

### จุดที่ต้องระวังเวลาแก้

- **กราฟต้องวาดด้วยพิกัดพิกเซลจริง** ห้ามใช้ `viewBox` หน่วยย่อ + `preserveAspectRatio="none"`
  เพราะการยืด viewBox จะยืดตัวอักษรแกนและลายเส้นประไปด้วยจนอ่านไม่ออก
- **ห้ามใส่ `transform` ให้ `.ring` ใน CSS** — `chart.js` กำหนด rotate พร้อมจุดหมุนไว้ใน attribute แล้ว
  CSS จะทับแล้วหมุนรอบจุด 0,0 จนวงหลุดออกนอกกรอบ
- **ยอดหัวหมวดต้องนับเฉพาะรายการในหมวดนั้น** ไม่งั้นเงินก้อนพิเศษจะถูกนับซ้ำสองที่
- **ขึ้น `VERSION` ใน `sw.js` ทุกครั้งที่แก้ไฟล์ในลิสต์**

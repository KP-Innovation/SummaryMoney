# FinFlow — การเงินของฉัน

เว็บแอปจัดการและ **ทำนาย** การเงินส่วนตัว สร้างจากชีต `Simulation พื้นที่จำลอง` ของผู้ใช้
เป้าหมาย: เก็บความสามารถ "จำลองอนาคต" ของ Excel ไว้ แต่ทำให้ **ไม่พัง** และ **กดใช้บนมือถือได้จริง**

> ข้อมูลตั้งต้นเป็นรายการจริงจากไฟล์ Excel — 11 เดือน (ม.ค.–พ.ย. 2569) · รายรับ 34 · รายจ่าย 158 รายการ

## ปัญหาที่แก้ให้แล้ว

| ปัญหาใน Excel | แก้ยังไง |

## ปฏิทิน = เช็กลิสต์ ไม่ใช่แค่ตารางดู

มี 2 โหมด สลับด้วยปุ่มบนสุด

### แก้ได้ทุกมิติตรงในปฏิทิน (one stop)
แตะรายการไหนก็ได้ในช่องเดือน → เปิดแผงที่แก้ได้ครบในที่เดียว

| แก้อะไรได้ | หมายเหตุ |
|---|---|
| **ชื่อรายการ** | เปลี่ยนได้อิสระ เช่น "ค่ากิน (บัตร CardX)" → "โปะบัตร CardX" |
| **จำนวนเงิน** | พิมพ์สูตรได้ `1547+2200` · `4398+6000` |
| **หมวด** | ประจำ / ผันแปร / หนี้-บัตร / เงินออม |
| **วันครบกำหนด** | 1–31 |
| **โน้ต** | เช่น "เดือนนี้โปะเพิ่ม 2,000" |
| **สถานะ + วันที่จ่าย** | กด ✓ พร้อมแก้ยอดจริงในครั้งเดียวได้ |
| **ลบรายการ** | ออกจากเดือนนั้น |

> **แก้ตรงนี้มีผลกับเดือนนั้นเดือนเดียว** — ภาษีเดือน ส.ค. 3,747 ไม่ทำให้เดือนอื่นเปลี่ยน
> ถ้าอยากเปลี่ยนทุกเดือน ให้ไปแก้ที่ **ภาระประจำ**

**เพิ่มของไม่คาดคิดได้ในช่องเดือนเลย** — ปุ่ม `+ เพิ่มรายการ` ท้ายทุกช่อง
เลือกได้ 3 แบบ: รายจ่ายไม่คาดคิด (ค่าซ่อมรถ) · รายรับพิเศษ · ให้ยืม-มีกำหนดคืน
ของที่เพิ่งเพิ่มจะถูกกางให้เห็นทันที ไม่หายเข้าไปในกลุ่มที่พับอยู่

**รายรับแสดงในช่องเดือนด้วย** (สีฟ้า มีเครื่องหมาย +) ติ๊กว่า "เข้าแล้ว" ได้เหมือนรายจ่าย
รายจ่ายผันแปรพับไว้ท้ายช่อง กด `+ ผันแปรอีก N รายการ` เพื่อกาง

### 📌 ปักหมุดเดือนที่สนใจ
แตะไอคอน 📌 ที่หัวเดือนไหนก็ได้ → เดือนนั้นถูกยกขึ้นไปไว้ **บนสุด** ในโซนโฟกัส

- ช่องที่ปักหมุดกว้างกว่าปกติ (2 คอลัมน์) อ่านเช็กลิสต์ได้สบายตากว่า
- ปักได้หลายเดือนพร้อมกัน · กด 📌 ซ้ำเพื่อเอาออก
- เดือนที่ปักยังคงอยู่ในกริดข้างล่างตามปกติด้วย

### โหมดรายปี — ดูภาพรวมทั้งปีรวดเดียว
12 ช่องเดือนเรียงกัน แต่ละช่องมีเช็กลิสต์ภาระประจำของเดือนนั้น

- **ส้ม = ยังไม่จ่าย · เขียว = จ่ายแล้ว** (ขีดฆ่า + เครื่องหมาย ✓)
- แตะรายการ → ใส่วันที่จ่าย (ตั้งต้นเป็นวันครบกำหนดของเดือนนั้นให้เลย) → กดยืนยันจบ
- แตะรายการที่เขียวแล้ว → เห็นว่าจ่ายเมื่อไหร่ + ปุ่มยกเลิกกลับเป็นยังไม่จ่าย
- หัวมุมขวาแต่ละเดือนบอก `จ่ายแล้ว/ทั้งหมด` · หัวปีสรุปทั้งปี + ยอดที่ยังไม่จ่ายรวม
- ปุ่ม **เตรียมภาระประจำให้ครบทั้งปี** สร้าง 12 เดือนพร้อมภาระประจำรวดเดียว
- แตะชื่อเดือน → กระโดดไปดูรายวันของเดือนนั้น
- แสดงเฉพาะ *ภาระที่ต้องจ่ายประจำ* ไม่รวมรายจ่ายผันแปรจิปาถะ (นับรวมไว้ท้ายช่องว่า `+ อื่นๆ N รายการ`)

### โหมดรายเดือน — ลงรายละเอียดระดับวัน

**ภาระประจำ** ใส่ครั้งเดียวในโปรแกรม แล้วมันขึ้นให้ทุกเดือนเอง
เปิดเดือนใหม่ = ได้รายการครบชุดทันที สถานะ "ยังไม่จ่าย" ทั้งหมด (กด "เติมภาระประจำ" ซ้ำได้ ไม่เกิดของซ้ำ)

**ติ๊กจ่ายแล้วตรงบนวันนั้น** — แตะวันในปฏิทิน → เห็นทุกรายการของวันนั้น → กด ☐ เป็น ☑
รายการที่ติ๊กแล้วจะถูกขีดฆ่า จุดบนปฏิทินจางลง และวันที่ครบทุกรายการจะขึ้น ✓ สีเขียว

**เตือนของที่เลยกำหนด** — วันที่ผ่านไปแล้วแต่ยังไม่ติ๊ก ช่องนั้นเป็นสีแดงพร้อมเครื่องหมาย `!`
หัวเดือนสรุปให้ว่า *"ติ๊กแล้ว 3/20 · ยังไม่จ่าย 33,494 ฿ · ⚠ เลยกำหนดแล้ว 1 รายการ"*

**ของไม่คาดคิด** — ปุ่ม `+ เพิ่มรายการ` เลือกได้ 3 แบบ:
- **รายจ่ายไม่คาดคิด** (ค่าซ่อมรถ ค่าหมอ) ลงวันไหนก็ได้
- **รายรับพิเศษ**
- **ให้ยืม — มีกำหนดคืน** → สร้าง 2 รายการพร้อมกัน: เงินออกวันนี้ + **เงินเข้าวันที่นัดคืน**
  ข้ามเดือนได้ ระบบสร้างเดือนปลายทางให้เอง จะได้ไม่ลืมว่ามีเงินก้อนนี้รออยู่

> **สำคัญ:** การติ๊ก "จ่ายแล้ว" เป็นสถานะเช็กลิสต์อย่างเดียว **ไม่กระทบยอดเงินใดๆ**
> (ทดสอบแล้ว: ติ๊กค่าห้อง 7,000 → ยอดรายจ่ายเดือนนั้นยังเป็น 40,494 เท่าเดิม)
> เพราะรายการนั้นถูกนับเป็นภาระของเดือนตั้งแต่แรกอยู่แล้ว การติ๊กแค่บอกว่า "จัดการไปแล้ว"

## สิ่งที่ทำให้ใช้ง่ายจริง

- **แก้ได้ทุกช่อง** — แตะที่ชื่อหรือตัวเลขแล้วพิมพ์ทับได้ทันที ไม่ต้องเปิดหน้าต่างใหม่
- **ช่องตัวเลขรับสูตร** — พิมพ์ `3000+500` หรือ `1200*2` แล้วมันคิดให้ (เหมือนที่เคยชินใน Excel)
- **โน้ตได้ทุกรายการ** — ปุ่ม ✎ ท้ายแถว มีโน้ตแล้วจุดเปลี่ยนเป็นสีเหลือง
- **เดือนใหม่สร้างเองอัตโนมัติ** — กด › ไปเดือนที่ยังไม่มี ระบบจะยกรายจ่ายประจำ/หนี้/เงินออมจากเดือนล่าสุดมาให้ ไม่ต้องพิมพ์ใหม่
- **แยก "จริง" กับ "คาดการณ์"** — กดปุ่ม ● / ○ สลับได้ กราฟจะเปลี่ยนเป็นเส้นทึบ/เส้นประให้เอง
- **สำรอง/กู้คืนเป็นไฟล์ JSON** — ปุ่ม ⋯ มุมล่างซ้าย

## กติกาคำนวณ (มีข้อเดียว)

```
ยอดยกมา + รายรับ + เงินก้อนพิเศษ − รายจ่าย = เหลือสุทธิ
เหลือสุทธิเดือนนี้ = ยอดยกมาเดือนหน้า        ← ต่อกันเป็นลูกโซ่
```

แก้อะไรก็ตาม ลูกโซ่ทั้งเส้นคำนวณใหม่หมดทันที
**ทดสอบแล้ว:** เพิ่มค่าห้อง ก.พ. 2,000 บาท → ทุกเดือนถัดไปขยับ −2,000 ทั้งเส้น · ลบรายการทิ้ง → ไม่มี `NaN` สักช่อง

> **หมายเหตุ:** ตัวเลขบางเดือนจะไม่ตรงกับชีตเดิม เพราะสูตรในชีต**ไม่ตรงกันเองอยู่แล้ว**
> (เช่น พ.ค. ยอดยกมาคำนวณไม่ลงตัว ต่างไป ~5,848) แอปนี้ยึดรายการจริงแล้วคำนวณใหม่ให้ถูก

### จุดที่ต้องระวังเวลาแก้

- **ห้ามเปลี่ยน `.tl-labels` เป็น `position: absolute`** — sticky ใช้กับ absolute ไม่ได้
  ชื่อแถวแกน Y จะหลุดจอตอนเลื่อนไปดูสิ้นเดือนบนมือถือ
- **วัดความกว้างเส้นเวลาหลังวางการ์ดลงหน้าแล้วเท่านั้น** — `host.clientWidth` รวม padding ของ `.main`
  ด้วย ใช้ตรงๆ จะคิดว่ามีที่มากกว่าจริง 52px แล้ววาดเส้นล้นจอ
- **กราฟต้องวาดด้วยพิกัดพิกเซลจริง** ห้ามใช้ `viewBox` หน่วยย่อ + `preserveAspectRatio="none"`
  เพราะการยืด viewBox จะยืดตัวอักษรแกนและลายเส้นประไปด้วยจนอ่านไม่ออก
- **ห้ามใส่ `transform` ให้ `.ring` ใน CSS** — `chart.js` กำหนด rotate พร้อมจุดหมุนไว้ใน attribute แล้ว
  CSS จะทับแล้วหมุนรอบจุด 0,0 จนวงหลุดออกนอกกรอบ
- **ยอดหัวหมวดต้องนับเฉพาะรายการในหมวดนั้น** ไม่งั้นเงินก้อนพิเศษจะถูกนับซ้ำสองที่
- **ขึ้น `VERSION` ใน `sw.js` ทุกครั้งที่แก้ไฟล์ในลิสต์**
- **หน้านี้ตั้ง `viewport-fit=cover` + status bar โปร่งใส** เนื้อหาจึงกินพื้นที่เต็มจอจริง
  ทุกที่ที่ชิดขอบบนต้องบวก `var(--sat)` (= `env(safe-area-inset-top)`) ไม่งั้นบน iPhone
  การ์ดใบแรกจะไปมุดอยู่ใต้ Dynamic Island — เดิมใส่ไว้แต่ `safe-area-inset-bottom` จนพลาดข้อนี้
